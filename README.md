# ScottOS 8x - Windows 11 Inspired Linux Distribution

🚀 A modern Linux distribution inspired by Windows 11 Fluent Design System with native taskbar, system sounds, themes, and AI integration.

## Features

✨ **Taskbar UI/UX** - Centered Windows 11-style taskbar
🔊 **System Sounds** - Windows 11 boot and system sounds
🎨 **Visual Theme** - Fluent Design colors, icons, and wallpapers
📁 **System Apps** - File Explorer, Settings, Store, and more
🌐 **Chrome Integration** - Seamless Google Chrome integration
🤖 **AI Features** - Built-in AI assistant and smart features

## Getting Started

1. Clone the repository
2. Follow the build instructions in `BUILD.md`
3. Configure your system with `config/`
